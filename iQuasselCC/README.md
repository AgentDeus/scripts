# iQuasselCC

**Quassel Core Client not a stand alone client.**

iQuasselCC is an iPhone-only client for [Quassel](https://quassel-irc.org) cores. Its layout and behaviour follow the
Android client: an app bar with the chat name and topic, the chat list in a left drawer, the nick list in a right drawer,
and the chat with an input line at the bottom. It does not connect to IRC itself. It connects to your Quassel core,
which stays on IRC for you and keeps your history.

## Features

| Area | What's there |
|---|---|
| Cores | Several saved cores. You can **connect to several at the same time** and switch between them from the drawer header. Passwords are kept in the Keychain. Auto-connect and auto-reconnect are supported. |
| Security | TLS via Quassel's STARTTLS-style negotiation. Untrusted (self-signed) certificates show the SHA-256/SHA-1 fingerprint and can be accepted once or always (pinned per core). |
| Core setup | A first-run wizard for unconfigured cores (admin user and storage backend). |
| Chat list | Chat lists (buffer views) synced from the core, networks you can collapse, activity colours, highlight badges, filtering, temporary or permanent hiding (hidden chats come back on new messages), unhide, rename, delete, join and part. |
| Chat | Backlog loaded on demand with infinite scroll back through history, date separators, the synced marker line, read state, highlights (from the core plus local nick detection), mIRC colours and formatting (bold, italic, underline, strike-through, monospace, reverse, hex colours), Quassel-compatible nick colours, clickable links, channels and nicks, copy, share, reply, query and whois. |
| Input | Multi-line input, send with return, per-chat drafts, sent-message history, tab completion of nicks and channels, a formatting bar with the mIRC colour picker, and all `/commands` (handled by the core, aliases included). |
| Nick list | Sorted by prefix (`~&@%+`), away users greyed out, search, user details (hostmask, account, server, idle and login time, channels), op/voice/kick/ban actions, ignore. |
| Core settings | Networks (servers, TLS, proxy, SASL, NickServ, reconnect, perform, rate limits, encodings, connect/disconnect), identities, chat lists, ignore list, highlight rules, aliases, core info (version, uptime, connected clients) and changing your core password. |
| App settings | Themes (Quassel light/dark, Material light/dark, Solarized light/dark, AMOLED), text size, timestamps, nick colouring, prefixes, hostmasks, real names, hiding join/part/quit, nick and mode changes, backlog sizes, notifications. |
| Notifications | Local notifications for highlights, private messages and, optionally, all channel messages. |

### iOS limitation

iOS suspends network sockets shortly after an app goes to the background. iQuasselCC asks for extra background time and
reconnects as soon as it comes back to the foreground. Your Quassel core stays connected to IRC the whole time, and the
backlog fills any gap. Notifications cannot be delivered while the app is suspended, because Quassel has no push service.

## Installing without a Mac (Windows or Linux)

You don't need a Mac. GitHub's macOS build machine compiles the app on every push and publishes an **unsigned IPA**:

1. Open the latest *iQuasselCC iOS build* run under the repository's **Actions** tab and download the
   `iQuasselCC-unsigned-ipa` artifact (a zip containing `iQuasselCC-unsigned.ipa`).
2. Sign and install it with your Apple ID:
   - **Windows:** [Sideloadly](https://sideloadly.io) (or AltStore's AltServer). Install iTunes and iCloud from apple.com
     first (not the Microsoft Store versions), connect the iPhone by USB, drag in the IPA, enter your Apple ID and press Start.
   - **Linux:** [AltServer-Linux](https://github.com/NyaMisty/alt-server) or [SideStore](https://sidestore.io)
     (SideStore can refresh the app on the phone itself, without a computer).
3. On the iPhone, turn on *Settings → Privacy & Security → Developer Mode*, and trust your Apple ID under
   *Settings → General → VPN & Device Management*.

With a free Apple ID the signature lasts **7 days**. Re-sign the app with the same tool, or let SideStore/AltStore
refresh it. Your accounts and settings are kept. A paid Apple Developer account ($99/year) gives 1-year signing and TestFlight.

## Building

Requirements: an iPhone with iOS 17 or newer. The app is iPhone-only: no iPad, no Mac. Apple only allows iOS apps to be compiled with Xcode, so building and installing it onto the iPhone needs a Mac with Xcode 15+ (or the included GitHub Actions workflow, which compiles on a hosted macOS machine and tests in an iPhone simulator).

1. Open `iQuasselCC/iQuasselCC.xcodeproj` in Xcode.
2. Pick your development team under *Signing & Capabilities*. Change the bundle identifier `app.iquasselcc.client` if you need to.
3. Run on a device or a simulator.

The project file is generated by `tools/generate_xcodeproj.py`. Run it again after adding or removing source files:

```sh
cd iQuasselCC && python3 tools/generate_xcodeproj.py
```

You can also use [XcodeGen](https://github.com/yonaskolb/XcodeGen) with `project.yml`.

The GitHub Actions workflow `.github/workflows/iquasselcc.yml` builds the app and runs the protocol tests on a macOS runner.

## Layout

```
iQuasselCC/
  Protocol/    QVariant + QDataStream codec, TLS socket, handshake and SignalProxy (DataStream protocol)
  Model/       Synced objects: Network, IrcUser, IrcChannel, BufferSyncer, BufferViewConfig, Identity, managers
  Session/     CoreSession (one per core), SessionManager (multi-core), accounts, settings, notifications
  Formatting/  mIRC formatting, message rendering, themes and nick colours
  UI/          SwiftUI screens (drawers, chat, input, nick list, settings, core settings)
iQuasselCCTests/  Decoder/encoder tests against frames captured from a real Quassel 0.14 core
```

## Protocol notes

- Probe: magic `0x42b33f00 | TLS`, then protocol list `0x80000002` (DataStream). Compression is not requested.
- Features are negotiated with the `FeatureList` (falling back to legacy bits): LongTime, LongMessageId, SenderPrefixes,
  RichMessages, SyncedCoreInfo, BufferActivitySync, SynchronizedMarkerLine and the others in `QuasselFeature.clientSupported`.
- The test fixtures are real frames. Each one must decode and re-encode to identical bytes.
